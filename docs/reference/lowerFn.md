# Function to support draw_correlation_plot

Function to support draw_correlation_plot

## Usage

``` r
lowerFn(data, mapping, method = "lm", ...)
```

## Arguments

- data:

  input df for ggplot

- mapping:

  mapping for ggplot

- method:

  plotting method for ggplot (default "lm")

- ...:

  other parameters to pass onto geoms

## Value

a ggplot object
