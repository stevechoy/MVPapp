# Function that stores the names and ranges of quantiles as a character string to be used in Figure footnotes etc (Not used)

Function that stores the names and ranges of quantiles as a character
string to be used in Figure footnotes etc (Not used)

## Usage

``` r
quantile_ranges_name(quantiles_df, df_orig, xvar)
```

## Arguments

- quantiles_df:

  Name of dataframe containing columns corresponding to number of
  quantiles

- df_orig:

  Name of original dataframe containing the continuous x-axis variable

- xvar:

  Name of x-axis variable to split by

## Value

a character string containing the quantile limits
