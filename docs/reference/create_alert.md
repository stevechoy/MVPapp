# Function that generates a shinyalert

Function that generates a shinyalert

## Usage

``` r
create_alert(
  ppm_name = "Firstname Lastname",
  ppm_email = "dummy.email@company.com"
)
```

## Arguments

- ppm_name:

  Name of Project Pharmacometrician

- ppm_email:

  Email of Project Pharmacometrician

## Value

a shinyalert() popup
