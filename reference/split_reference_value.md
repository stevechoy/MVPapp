# Split reference values evenly between lower and upper bound for batch run table

Split reference values evenly between lower and upper bound for batch
run table

## Usage

``` r
split_reference_value(reference_value, lower_bound, upper_bound)
```

## Arguments

- reference_value:

  The reference value to be used for splitting

- lower_bound:

  The lower bound to be used for splitting

- upper_bound:

  The upper bound to be used for splitting

## Value

a list of splits excluding reference value
