# Function that turns blank values into ".(blanks)" group

Function that turns blank values into ".(blanks)" group

## Usage

``` r
handle_blanks(df, column_name)
```

## Arguments

- df:

  Input dataframe

- column_name:

  Name of column (must be character type) to check for blanks

## Value

a dataframe with the blank values converted into ".(blanks)
