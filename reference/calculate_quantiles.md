# Function to split a continuous X-variable for a number of quantiles

Function to split a continuous X-variable for a number of quantiles

## Usage

``` r
calculate_quantiles(df, xvar, num_quantiles)
```

## Arguments

- df:

  Name of dataframe

- xvar:

  Name of x-axis variable to split by

- num_quantiles:

  Number of discrete quantiles

## Value

a dataframe containing the quantile limits
