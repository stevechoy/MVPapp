# Generating log breaks and axis labels, mainly for plotly

Generating log breaks and axis labels, mainly for plotly

## Usage

``` r
generate_log_breaks(base_values, start, end)
```

## Arguments

- base_values:

  the base value(s) to apply the exponent to

- start:

  the starting exponent

- end:

  the last exponent

## Value

a numeric
