# Function that categorizes X-axis variable according to the quantile df

Function that categorizes X-axis variable according to the quantile df

## Usage

``` r
categorize_xvar(df, quantiles_df, xvar)
```

## Arguments

- df:

  Name of dataframe containing columns corresponding to number of
  quantiles

- quantiles_df:

  Name of dataframe containing the quantiles limits

- xvar:

  Name of x-axis variable to split by

## Value

a character string containing the quantile limits
